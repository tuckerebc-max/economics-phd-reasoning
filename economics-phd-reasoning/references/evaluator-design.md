## `OPT-67-ECONOMICS` evaluator

**Primary evidence:** contribution memo, model / assumptions audit, identification plan, analysis / robustness packet, interpretation memo, defense questions, revision log.

**Dimensions:** contribution; assumptions; identification; method fit; robustness; uncertainty; interpretation; methodological plurality; response to critique; reproducibility.

**Critical failures:** invented result, unsupported causal claim, hidden assumption that changes the conclusion, or code output accepted without substantive validation.

**Challenge set design:** confounded regression; weak instrument; model with hidden assumption; robustness failure; conflicting theoretical explanation; replication / interpretation mismatch.

**Improvement loop:** diagnose identification or assumption failure → revise claim / design → rerun robustness packet → compare whether the claim is appropriately narrowed.
